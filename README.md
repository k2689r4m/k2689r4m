# Full-Stack Developer

### Backend · Full-Stack · Realtime · Data · Automation

다양한 분야의 서비스를 설계하고 개발해 온 풀스택 개발자입니다.

Node.js 기반 백엔드 개발을 중심으로 프론트엔드, 데이터베이스 설계, 외부 API 연동, 실시간 데이터 처리 등 서비스 전반을 개발해 왔습니다.

상업용 부동산, 금융·자동거래, 교육, 산업 모니터링 등 다양한 도메인의 프로젝트를 경험했으며, 요구사항 분석부터 설계, 개발, 배포까지 전체 개발 과정을 주도적으로 수행한 경험이 있습니다.
